# Installers (local only, git-ignored)

Drop proprietary installers here before running the matching manual module.

| Module | Put here |
| --- | --- |
| `./install.sh starccm` | `STAR-CCM+*_linux-x86_64.tar.gz` (or an already extracted `starccm+_*` folder, or the bare `.aol`) |

Everything in this folder except this README is ignored by git.
To keep installers elsewhere (e.g. a USB stick): `STARCCM_INSTALLER_DIR=/path ./install.sh starccm`
